# road to coffee drip by open arm

オープンソースのロボットアーム **SO-101** と **[LeRobot](https://github.com/huggingface/lerobot)** で、
最終的に **ハンドドリップでコーヒーを淹れる（100〜200ml）** ところまで到達することを目指す記録。

到達できるかどうかは、正直まだ分からない。分からないなりに、
**何を買い、何につまずき、どこまでできたか**を残していく。

## なぜこれを公開するのか

この領域は日本語の情報が断片的で、しかも古くなるのが速い（SO-100 → SO-101、LeRobot の API 変更など）。
「実際に買って、実際に詰まった」記録は、それ自体が一次情報になる。

たとえば本リポジトリを書き始めた時点で、すでに次のことが分かっている。
どれも商品ページを普通に読んだだけでは気づきにくい。

- 秋月電子の SO-101 キット（¥46,280）には **3D プリントパーツが入っていない**。別売 ¥7,280 が必須
- **カメラも別売**。模倣学習はカメラ画像が入力なので、カメラがないと学習が成立しない
- リーダー＋フォロワーで USB 2 ポート、カメラで 1〜2 ポート。**ノート PC だとポートが足りない**
